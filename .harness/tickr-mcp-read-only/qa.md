## Limits and observations

1. **Browser journeys not run.** No browser automation exists in this session. A person needs to run C13L–C15L in MCP Inspector's browser UI and click Disconnect in Profile → Connected apps.
2. **UI not reviewed (C18).** The consent page, the `/auth` Continue panel and the Connected apps card have not been through `get-review-rules`, `check-comprehension` or `inspect-spacing`.
3. **Shared rate limit.** OAuth endpoints count toward Better Auth's global limit of 100 requests a minute per IP, together with normal app sign-in traffic. For real use this is unlikely to bite, but behind a shared NAT or proxy (one IP for many users) it could. Not a requirement failure, but worth watching in staging.
4. **Old access token after refresh.** A refreshed client's previous access token stays valid until it expires (at most 15 min) unless the app is disconnected. Disconnect revokes everything, which REQ-2 requires.
5. **Local configuration.** To test on :3000, `.env` needs `BETTER_AUTH_URL=http://localhost:3000` (not `https://`), `MCP_ENABLED=true`, and the tester's user ID in `MCP_PILOT_USER_IDS`.
6. **Branch data left behind.** The two synthetic users and the `MCP E2E Inspector` and `QA Inspector` OAuth client rows remain on the branch. QA fixtures, grants and sessions were removed.
