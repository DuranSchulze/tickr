# Stage 5 · Initial Zoom Out Review

Target: [Trackly weekly department exports](docs/designs/weekly-department-reports.md), lines 1–125. Both independent reviewers completed.

## Zoom Out

| ID  | Severity | Design lines | Finding                                                                                                                                                                                                                                                                                                                                                                                  |
| --- | -------- | ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Z1  | Major    | 47, 55, 105  | Regenerating old weeks from today's roster can move pre-transfer work into the new department's historical report. New hires can also show seven `NO_TIME` rows for dates before they joined. Define reporting-period attribution separately from current download authorization. The supplied membership and entry schemas show current assignment and no per-entry department history. |
| Z2  | Major    | 55, 109      | The proposed child route depends on the selected workspace. The existing app parent loads that workspace, can redirect to onboarding, and can block the child on that workspace's subscription. Resolve the report workspace independently or make the parent report-aware.                                                                                                              |
| Z3  | Major    | 59, 101, 105 | The manual Timesheet fetches entries by start and aggregates them on the local start date. Using those day cells to suppress `N/A` misses work crossing midnight or the start of the week. Share the overlap check while preserving the manual Timesheet's existing hour allocation.                                                                                                     |
| Z4  | Major    | 55, 109      | A link accessible to any eligible department admin points to a delivery job deleted with its original recipient. Clarify the link's ownership and lifespan or give it a recipient-independent reference.                                                                                                                                                                                 |
| Z5  | Nit      | 49, 107      | Reuse the existing Excel workbook builder and daily row formatting primitives. A dedicated PDF layout remains justified because the current grouped renderer consumes a different shape.                                                                                                                                                                                                 |
| Z6  | Nit      | 109          | Enforce a hard 90-day limit in the lookup if intended. The worker stops pruning when delivery is paused.                                                                                                                                                                                                                                                                                 |

## Inventive Catalyst

| ID  | Severity | Design lines          | Finding                                                                                                                                                                                                                                                                                                                                                     |
| --- | -------- | --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Z7  | Major    | 39, 53, 111, 122–123  | Link-only delivery currently depends on finishing PDF generation. Prepare the link independently and admit PDF rendering only within a defined worker budget. A CPU-bound render needs an admission guard or an interruptible renderer. Verify link-only delivery when rendering cannot proceed. Conservative admission can omit some attachments that fit. |
| Z8  | Major    | 39, 43, 111, 115, 123 | Retiring legacy jobs alone leaves the enqueue cursor or advanced week intact. A mid-period cutover can miss that week's department recipients. Schedule cutover between reporting periods after legacy invocations drain. Mid-period rollout needs atomic schedule and job reconciliation.                                                                  |
| Z9  | Nit      | 33–34, 41, 47, 111    | Each recipient can trigger an identical PDF rebuild. Measure first. If repeated renders threaten capacity, consider bounded reuse within a worker invocation and retain per-recipient roster checks. This trades CPU time for memory use and potentially older attachment data.                                                                             |
